ΚΛΉΜΗΣ Ὁ ΡΩΜΑΊΟΣ (Климент Римский, ~30-100 н.э.) — 4-й Епископ Рима (после апостола Петра, Лина и Анаклета) (по Иринею Лионскому, Против Ересей III, 3, 3). Главное произведение — 1 Послание к Коринфянам (~96 г.) — самое Длинное Послание Apostolic Fathers (~25 000 слов, 60 глав).

Главные темы Климента: 1. Εἰρήνη (Мир) — восстановление Порядка в Коринфской Церкви (молодёжь свергла старейшин). 2. Ἱεραρχία (Иерархия) — Порядок по Образу Римского Военного. 3. Μετάνοια (Покаяние) — Коринфяне должны Покаяться. 4. Μαρτύριον (Мученичество) — Климент сам примет Мученичество (по традиции). 5. LXX — Климент Использует Греческую Библию (Q53) для Доказательств. 6. «Симфония (Гармония) Двух Заветов» (Ветхого и Нового)».
