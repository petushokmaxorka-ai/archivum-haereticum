4 ВЕЛИКИЕ РЕЛИГИИ ИНДОНЕЗИИ + ИХ СИНКРЕТИЗМЫ:

  1. HINDU INDONESIA (V Jahrhundert н.э. — наст.) — Балийский Индуизм (Agama Hindu Dharma). Батавия = центр индуизма. Храмовый комплекс Прамбанан (Prambanan) — крупнейший ИНДУИСТСКИЙ храм за пределами Индии
  2. BUDDHA INDONESIA (V в. н.э. — наст.) — Шривиджая (Srivijaya) VII-XIII вв. — крупнейшая Буддийская империя, морская торговая держава. Боробудур (Borobudur) IX в. — крупнейший Буддийский памятник мира
  3. ISLAM INDONESIA (XIII в. — наст.) — 200+ млн мусульман (крупнейшая мусульманская страна мира). Принесли СУФИИ (Q16) — 7 орденов тарика (tarekat)
  4. АНИМИЗМ / КАХАРИНГАН / АЛУК ТО ДОЛО — коренные религии: Dayak (Борнео), Asmat (Папуа), Batak (Суматра), Toraja (Сулавеси)
