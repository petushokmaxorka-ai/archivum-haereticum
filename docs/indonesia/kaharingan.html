Q50.4Kaharingan · Кахаринган (Dayak, Борнео)

8 стихов · Bahasa Ngaju (Dayak) + Bahasa Indonesia + рус. · 7 Небес + 7 Земель · Ranying Hatalla (Верховный Бог) · Синкретизм Буддизма + Анимизма
◆ FIDELIS ✚ MYSTICA ✠ KAHARINGAN
◀ Q50 — Indonesia · CORPUS DIVINUS

KAHARINGAN (Кахаринган) — коренная религия народа Dayak (Дайяк) на острове Борнео (Калимантан). ~3 миллиона верующих, признана государственной религией Индонезии. Kaharingan = «Жизнь, Существование, Энергия Жизни». Верховный Бог — Ranying Hatalla (Раныйинг Хаталла), буквально «Тот, Кто обитает в свете». Синкретизм с Буддизмом Махаяны (через Шривиджаю, VII в.) и Австрало-Меланезийским анимизмом.

Главные мифы Kaharingan: Tambun Bunai (7-частный миф о Сотворении Мира) + Manasai (Ритуал Жатвы) + Tiwah (Вторичные Похороны).

1. Ranying Hatalla (Раныйинг Хаталла) — «Живущий в Свете»

Q50 — Kaharingan, Текст «Tambun Bunai» · Bahasa Ngaju (Dayak) + Bahasa Indonesia
Ranying Hatalla = «Ranying» (Сияющий, Свет) + «Hatalla» (Тот-Кто-Живёт, Бог)
«Хаталла Руа Тангкьянг Джала Бунга (Hatalla Rua Tangkyang Jala Bunga)»
«Бог-Отец-Живущий-в-Небесном-Цветке»
«Ranying Hatalla создал 7 Небес и 7 Земель»
«Ranying Hatalla (Раныйинг Хаталла) — Верховный Бог Кахаринган. «Раныйинг» (Ranying) = «Сияющий, Тот-Кто-Излучает Свет». «Хаталла» (Hatalla) = «Святой, Божественный». Создал 7 Небес (Banua Tujuh) и 7 Земель (Banua Pitu). Сам живёт на Верхнем Небе (Banua Langit)».
Связь с Q50: Ranying Hatalla = Q1 Элохим (Яхве, Бог Света) = Q14 Брахма (Свет-из-Тьмы, Насаньягарбха) = Q22 Один Альфöðр (Светлый Отец) = Q33 Гелиос (Свет) = Q20 Атум (Свет Первобытный) = Q36 Wagyl (Радужный Змей, Свет Австралии).

2. Tambun Bunai (Тамбун Бунаи) — «Сотворение Мира» (Часть 1: 7 Небес)

Q50 — Kaharingan · Текст «Тамбун Бунаи» (7 глав) · Bahasa Ngaju (Dayak)
Tambun Bunai — «Сотворение, Созидание, Упорядочение»
1. Banua Taloh — Первое Небо (Воды)
2. Banua Pahu — Второе Небо (Земля)
3. Banua Malino — Третье Небо (Свет)
4. Banua Palamba — Четвёртое Небо (Священная Гора)
5. Banua Jawa — Пятое Небо (Жизнь)
6. Banua Indang — Шестое Небо (Святые Предки)
7. Banua Langit — Седьмое Небо (Ranying Hatalla)
«Tambun Bunai = Сотворение Мира (дословно «Сотворение-Закладывание»). Ranying Hatalla создал 7 Небес (Banua Tujuh): 1. Banua Taloh (Воды), 2. Banua Pahu (Земля), 3. Banua Malino (Свет), 4. Banua Palamba (Гора), 5. Banua Jawa (Жизнь), 6. Banua Indang (Предки), 7. Banua Langit (Обитель Бога)».
Связь с Q50: 7 Небес Dayak = Q33 7 Сфер (Гелиос-Гелиос) = Q5.2 7 Небес (Ислам, 7 Самават) = Q22 9 Миров Иггдрасиль (Сканд.) = Q14 14 Лок (Бхагавата Пурана) = Q23 13 Миров Майя. 7 = САКРАЛЬНОЕ ЧИСЛО (Бог = 7-й День = 7 Священных).

3. Burung Tingang (Бурунг Тинганг) — «Птица-Вестник»

Q50 — Kaharingan · Bahasa Ngaju (Dayak)
Burung Tingang — «Белая Цапля» (или «Длиннохвостая Птица»)
«Tingang pambelom banyu — «Цапля-приносящая-воду»
«Burung Tingang спустилась из Banua Taloh (Водного Неба) и принесла людям СОМАНА (грязь, ил со дна мирового океана)»
«Из Сомана Ranying Hatalla создал остров Борнео»
«Burung Tingang (Белая Цапля / Птица-Мать) — священная птица Dayak. «Принесла Соману (ил) из Banua Taloh (Водного Неба), и из этой ила Ranying Hatalla создал остров Борнео (Калимантан)». «Tingang = Священная Птица, подобно Журавлю в мифе Майя, Петуху в Кельтской, Ворону в Сибирской»».
Связь с Q50: «Птица принесла землю» = Q41 «Голубь, принёсший масличный лист» (Q1, Q17, Q33, Q37, Q48 — везде!) = Q23 Майя «Дух-Птица Хуракан сотворил мир» (Пополь-Вух) = Q34 Tezpi посылает ястреба и колибри = Q36 Wagyl (Радужный Змей, создал горы) = Q22 Локи + ворона (Сканд.).

4. Maharaja Sangiang (Махараджа Сангианг) — «Дух-Царь»

Q50 — Kaharingan, культ предков · Bahasa Ngaju (Dayak)
Maharaja Sangiang — «Великий Царь-Дух» (Maharaja = «Великий Царь», Sangiang = «Духи»)
«Maharaja Sangiang — это Предки (Мёртвые), которые СТАЛИ БОГАМИ после смерти»
««Явянджат Санджуанг Маджахэ (Lelakian Mahapahariwong)» — Ритуал вторичных похорон (Tiwah)»
«Maharaja Sangiang (Махараджа Сангианг) — Духи Предков, ставшие богами после смерти. Это УНИКАЛЬНО для Кахаринган: Предки = боги. «Sangiang = умершие, ставшие священными». «Ranying Hatalla — Верховный, Maharaja Sangiang — его «Заместители» (предки)».
Связь с Q50: Предки = боги = Q14 Pitṛs (Питри, Индуизм) = Q22 Dísir (Скандинавские Духи-Женщины) = Q43 Lemures, Manes (Римские Предки) = Q35 Erlik (Шаманский Предок-Смерть, Сибирь) = Q47 uKulunkulu (Зулу, Предки-Духи) = Q34 Mictlantecuhtli (Ацтекский Предок-Смерть) = Q1 «Бог Авраама, Исаака, Иакова».

5. Liau (Лиау) — «Дух-Покровитель»

Q50 — Kaharingan · Bahasa Ngaju (Dayak)
Liau (Лиау) — «Дух, Душа»
«В каждом человеке живёт Liau — его Дух-Покровитель»
«Когда человек умирает, его Liau возвращается в Banua Indang (Шестое Небо, Небо Предков)»
«Sakunau Liau — Ритуал Отправки Духа Предка в Небо»
«Liau (Лиау) — душа-хранитель каждого человека, животного, дерева, камня. Пока человек жив, Liau живёт в нём. Когда человек умирает, Liau уходит в Banua Indang (Шестое Небо Предков) и ждёт своей очереди стать Maharaja Sangiang».
Связь с Q50: «Liau» (Душа-Дух) = Q1 «נֶפֶשׁ (Нефеш)» (евр. Душа) = Q2 «ψυχή» (Греч. Психея) = Q14 «Ātman» (Санскр. Атман) = Q22 «Hugr» (Одн. Душа) = Q33 «θυμός» (Греч. Титос, Жизненный Принцип) = Q47 «Jīva» (Джайн, душа).

6. Tiwah (Тивах) — «Вторичные Похороны»

Q50 — Kaharingan, Ритуал · Bahasa Ngaju (Dayak)
Tiwah (Тивах) — «Кости, Останки, Вторичные Похороны»
«Когда Dayak умирает, тело хоронится на 6-12 месяцев. Затем кости ВЫКАПЫВАЮТСЯ и помещаются в Sandung (Дом-Проводник)»
««Церемония Тивах (Tiwah) — самая сложная и самая дорогая в Кахаринган»
«Цель: Отправить Liau (Дух) умершего в Banua Indang (Небо Предков)»
«Tiwah (Тивах) — ВТОРИЧНЫЕ ПОХОРОНЫ Dayak. Dayak = один из немногих народов мира, кто хоронит ДВАЖДЫ. Первый раз: тело. Второй раз (через 1-3 года): только кости. Sandung (Дом-Проводник) — священная постройка, где хранятся кости до отправки в Banua Indang (Небо Предков)».
Связь с Q50: «Вторичные похороны» = Q20 Египетские Мумии (промежуточная стадия) = Q23 Майя (Помещение в Пирамиду) = Q37 Маори (Tangi Wāhi, висячие клетки) = Q22 Погребальный Корабль (Snekke) = Q43 Римские Костницы (Catacomb) = Q34 Тольтекские Костницы. ВТОРИЧНЫЕ ПОХОРОНЫ = UNIVERSAL!

7. Belian (Белиан) — «Шаманский Ритуал» (Целительство)

Q50 — Kaharingan · Bahasa Ngaju (Dayak)
Belian (Белиан) — «Лечение, Защита, Церемония»
««Белиан — обрядовый танец-транс с Manasara (Шаман) в центре»
«Manasara входит в Lua (Транс) через Бурунг Понг (Птица Удара-Барабан)»
«Цель Белиан: общение с Maharaja Sangiang, лечение болезни, защита деревни»
«Belian (Белиан) — Шаманский Ритуал Кахаринган. Manasara (Манасара) = Шаман-Целитель. Во время Белиан: 1. Шаман входит в транс (Lua). 2. Издаёт звуки птиц и зверей (звукоподражание). 3. Maharaja Sangiang «входит» в шамана. 4. Исцеляет больного. 5. Прорицает будущее».
Связь с Q50: Belian (Шаманский Ритуал) = Q35 Шаманские Камлания (Сибирь) = Q37 Tohunga Maōri (Новая Зеландия) = Q22 Völva (Сканд. Шаманизм) = Q46 Шаманский Сплит (стрижка волос) = Q19 Орфей нисходит в Ад. «Шаман = Между Мирами»!

8. Modang (Моданг) — «Жертвоприношение Животных»

Q50 — Kaharingan · Bahasa Ngaju (Dayak)
Modang (Моданг) — «Жертвоприношение, Подношение»
««Даяк приносит жертву (Modang): 1. Рис (Sinyam) — для Ranying Hatalla. 2. Кур (Ayam) — для Maharaja Sangiang. 3. Кабан (Bawi) — для Liau предков. 4. Птица (Burung) — для Burung Tingang»
«Modang проводится в Священном Доме (Balai Adat) с барабанами и пением»
«Modang (Моданг) = Жертвоприношение. В Кахаринган 4 типа жертв: 1. Sinyam (Рис) — Ranying Hatalla (Верховному Богу). 2. Ayam (Курица) — Maharaja Sangiang (Предкам-Духам). 3. Bawi (Кабан) — Liau (Семейным Духам). 4. Burung (Птица) — Burung Tingang (Птице-Матери)».
Связь с Q50: Modang (Жертвоприношение) = Q33 «Гекатомба Зевсу» (Греция) = Q1 «Жертва Ноя (Быт 8:20)» (Быт 8:20) = Q17 «Утнапиштим принёс жертву на вершине горы» (табл. XI) = Q7 «Yasna (жертва Ахура Мазде) = Q48 «Все Потоп-Герои приносят жертву после потопа» = УНИВЕРСАЛЬНЫЙ ритуал!
