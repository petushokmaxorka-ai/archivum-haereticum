ΣΧΟΛΉ ἈΛΕΞΑΝΔΡΕΊΑΣ (Александрийская Богословская Школа / Διδασκαλεῖον) — Первая в Мире Христианская Богословская Школа (180-400 н.э.) — «Университет Древнего Мира» (Модестос: «Светильник Истины»). Расположена в Александрии Египетской (Серп Земли, Дельта Нила) — Второй по Величине Город Римской Империи. Главные Преподаватели: Афинагор (II в.) → Пантен (150-200) → Климент (155-215) → Ориген (185-253) → Иерокл (III в.) → Дидим Слепой (313-398). Главные Ученики: Афанасий (ученик Дидима), Арий (ученик Лукиана, Антиохия), Евагрий Понтийский, Григорий Чудотворец, Василий Кесарийский, Григорий Назианзин.

Главные Особенности Александрийской Школы: 1. Διδασκαλεῖον (Огласительное Училище) — Школа для Оглашённых (κατηχούμενοι) и Крещёных (πιστοί). 2. «Γνῶσις (Познание) + Πίστις (Вера) — НЕ Противопоставлены — Знание = Завершение Веры» (Климент, Q55). 3. «Ἀλληγορικὴ Ἑρμηνεία (Аллегорическое Толкование) — Библия = Многослойный Текст: Буквальный + Аллегорический + Мистический» (Ориген, Q52). 4. «Ἀπολογητική (Апологетика) — Защита Христианства от Гностиков (Q57), Философов (Q33), Иудеев (Q3)». 5. «Ἕνωσις Θεοῦ (Единение с Богом) — Через Логос (Q55) и Молитву». 6. «Ἀπαράβατον (Непреложность) — Передача Учения от Учителя к Ученику — «Парадигматическая» Преемственность».
