# Русский слой канона LXX: исходники перевода

Здесь лежит всё, из чего собирается русский слой читалки `docs/olp-vethozaveta/kanon/`: дословный перевод с греческого текста Септуагинты (Rahlfs 1935), а не с масоретского текста и не Синодальный.

## Что где

| Путь | Что это |
|---|---|
| `prep.py` | разбор источников в `greek/<книга>.json` и `csl/<книга>.json` (формат `{"гл": {"ст": текст}}`) |
| `greek/` | греческий текст: Ральфс (данные eliranwong, MyBible); Даниил, Сусанна и Вил — Феодотион (CCAT) |
| `csl/` | церковнославянский текст 1751 г. в гражданском шрифте (my-bible.info); `csl_ps151.json` — Пс 151, на странице источника он без номеров стихов |
| `work/in/<книга>/<гл>.json` | входные главы для переводчиков |
| `work/out/<книга>/<гл>.tr.json` | черновой перевод |
| `work/out/<книга>/<гл>.rv.json` | перевод после независимой сверки с греческим, `csl_map` — выравнивание славянских стихов по содержанию, `changes` — журнал правок (правки выравнивания книги помечены «H:») |
| `work/out/<книга>/_harmonized` | метка: книга прошла выравнивание имён, формул и терминов по всей книге |
| `work/STYLE.md` | правила перевода (обязательны для всех этапов) |
| `work/REVIEW.md`, `work/HARMONIZE.md`, `work/TASK_*.md` | порядок работы на этапах сверки и выравнивания |
| `work/jobs/` | разбивка книг на задания |
| `work/check.py` | проверка файлов перевода: стихи, пометки, скобки, длина, ссылки `csl_map` |
| `work/build.py`, `work/publish.sh` | сборка книг с меткой `_harmonized` в `docs/olp-vethozaveta/kanon/data/` и пересчёт `index.html` |

## Этапы

1. Перевод главы с греческого по `STYLE.md` (`.tr.json`).
2. Независимая сверка каждого стиха с греческим и выравнивание славянского текста (`.rv.json`).
3. Выравнивание имён, формул и терминов по всей книге (метка `_harmonized`).
4. Сборка: `sh work/publish.sh`.

Проверка: `python3 work/check.py --all rv` и `python3 work/check.py --all tr` должны печатать `OK`. Состояние по книгам: `python3 work/bookstatus.py`.

## Состояние на момент остановки

- **Опубликованы в читалке (прошли все этапы):** 1–4 Царств, Иисус Навин, Судьи, 1–2 Паралипоменон, 2 Ездры (греч. 1 Ездры), Неемия, 1–3 Маккавейские, Товит, Премудрость Соломона, Сирах, Молитва Манассии, 3 Ездры (переведена со славянского: греческий текст не сохранился).
- **Сверены, ждут выравнивания по книге:** Бытие, Исход, Левит, Числа, Второзаконие, Руфь, Ездра, Есфирь, Иов, Псалтирь, Притчи. Иудифь: сверена только гл. 16, гл. 1–15 ждут сверки.
- **Переведены, ждут сверки:** Екклесиаст, Песнь песней, Исаия (сверены 2 главы из 66), Даниил, Осия, Иоиль, Амос, Михей, Аввакум, Софония, Захария, Плач, Послание Иеремии, Варух.
- **Перевод не закончен:** Иеремия (42 из 52 глав), Иезекииль (44 из 48), Малахия (0 из 3).
- Авдий, Иона, Наум, Аггей: в читалке остаётся прежний перевод Винокурова.

Перевод выполнен ИИ-агентами. Каждый опубликованный стих сверен с греческим вторым, независимым проходом, но филолог-человек текст не вычитывал.
