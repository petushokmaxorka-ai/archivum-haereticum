# Правила перевода «Архива»: Септуагинта → русский, дословно

Цель — **точный дословный перевод греческого текста Септуагинты** (издание A. Rahlfs, 1935) на современный русский язык. Это «русский слой» читалки канона LXX в archivum-haereticum: читатель видит рядом греческий оригинал, церковнославянский текст 1751 года и этот перевод.

## Главное правило
Переводится **только данный греческий текст**. Не еврейский (масоретский) текст, не Синодальный перевод и не чьё-либо толкование.
- Не «исправляй» греческий по еврейскому и не подгоняй его под привычный Синодальный текст. Если у LXX другие числа, имена, порядок слов, лишние или недостающие фразы, иной смысл — переводи **то, что написано по-гречески**.
- Не подставляй по памяти формулировки Синодального перевода. Каждую фразу строй заново от греческого.
- Никаких комментариев, сносок и пояснений внутри перевода.

## Дословность
- Сохраняй строй греческого предложения, насколько позволяет русская грамматика: порядок членов, сочинительное «и» (καί) в начале фраз, причастные обороты (передавай причастием или придаточным, но не выбрасывай), повторы, семитизмы («и было», «пред лицом», «сыны Израиля», «от лица», «во дни те», «смертью умрёт»).
- Переводи **каждое** значимое слово. Не сокращай и не пересказывай. Не объединяй и не дроби стихи: один стих на входе — один стих на выходе.
- Слова, которых нет в греческом, но без которых русская фраза не складывается, ставь в **[квадратных скобках]**: «и он [был] царём». Скобок должно быть немного: только там, где без них никак.
- В греческом источнике нет пунктуации. Расставь нормальную русскую пунктуацию по смыслу.
- **Прямая речь** — всегда через двоеточие, без кавычек, с прописной буквы после двоеточия: «и сказал Господь Иисусу, говоря: Моисей, служитель Мой, скончался…». Речь, продолжающаяся в следующих стихах, кавычек тоже не получает. Внутренняя цитата в речи — «ёлочками».
- Язык — современный литературный русский, слегка возвышенный, без архаики: «сказал», а не «рече»; «вот», а не «се»; «ибо / потому что», а не «зане». Устоявшиеся церковные термины сохраняй (см. словарь).
- Числа пиши словами, как в тексте: «сорок лет», «три тысячи».
- Служебные пометки источника вида `[a]`, `[b]`, `[.1]`, `[.2]` оставляй **в тех же местах** перевода, дословно, с теми же скобками.

## Бог и священные имена
- κύριος (о Боге) → **Господь**. Никогда не «Яхве», не «Иегова».
- ὁ θεός → **Бог**; κύριος ὁ θεός → **Господь Бог**; ὕψιστος → **Всевышний**; παντοκράτωρ → **Вседержитель**; κύριος σαβαωθ → **Господь Саваоф**; κύριος τῶν δυνάμεων → **Господь сил**.
- Местоимения, относящиеся к Богу, пиши с прописной: Он, Его, Ему, Ты, Твой, Я, Мой (когда говорит Бог), а также относительные «Который, Которого» об Боге.
- πνεῦμα κυρίου / θεοῦ → Дух Господень / Дух Божий.
- κύριος о человеке → «господин»; δέσποτα → «владыка».

## Имена собственные
- Общеизвестные лица и места называй традиционно по-русски: Давид, Соломон, Саул, Самуил, Илия, Елисей, Иисус (сын Навин), Моисей, Аарон, Израиль, Иуда, Вениамин, Ефрем, Манассия, Иерусалим, Сион, Египет, Вавилон, Навуходоносор, Ассирия, Иордан, Ливан. Также традиционно: Σηων → **Сигон** (не «Сион», чтобы не путать с Σιων — Сион), Ωγ → Ог, Ιεφθαε → Иеффай, Σαμψων → Самсон, Δαλιδα → Далида; εφουδ/εφωδ/εφωθ → ефод (одно слово). Колена и праотцы — только традиционно: Рувим, Симеон, Левий, Иуда, Иссахар, Завулон, Дан, Неффалим, Гад, Асир, Иосиф, Вениамин, Ефрем, Манассия; Авраам, Исаак, Иаков, Ной, Адам, Ева, Сим, Хам, Иафет.
- Прочие имена передавай **с греческой формы** (как это делает церковнославянская традиция), а не с еврейской: β → в, η → и, θ → ф, ει → и, αι → е, οι → и, ου → у, ω → о, υ → и (после гласной часто в), γγ → нг, χ → х, придыхание не передаётся. Примеры: Αρμαθαιμ Σιφα → Армафаим Сифа; Ελκανα → Елкана; Αβεσσαλωμ → Авессалом; Ιωαβ → Иоав; Αχααβ → Ахав; Ιεζαβελ → Иезавель.
- Если греческий даёт иное имя, чем еврейский текст, пиши греческое.
- Одно и то же лицо (или место) в пределах книги называй всегда одинаково. Если греческий лишь **пишет** одно имя по-разному (Ρηχαβ/Ρεκχα, Σαδωκ/Σαδδουκ, Θολμι/Θολμαι), выбери одну форму — по самому частому написанию — и держи её. Отдельную форму сохраняй только тогда, когда греческий даёт **действительно другое имя** (Μεμφιβοσθε вместо Ιεβοσθε) или когда это явно разные лица.

## Сквозные решения для всех книг (уточнения по итогам ревью)
- ἀλλογενής → **чужеродный / чужеродец** (не «иноплеменник» — это ἀλλόφυλος; не «иноземец», не «инородный»). ἀλλότριος → «чужой» (о человеке — «чужой, чужеземец»).
- Имена на -αιας/-αια передаются через «-ея» (αι → е, как -ιας → -ия): Σαμαιας → **Самея** (Самеи, Самею), Μαασαιας → Маасея, Ασαιας → Асея. Не путать с Σεμεϊ/Σεμει (другое имя) → Семей.
- Ημαθ / Αιμαθ (Емаф, город и область) → **Емаф** во всех книгах (традиционно).
- κινύρα → **кинира** (мн. киниры); κιθάρα → кифара.
- θώραξ → панцирь.
- Нетрадиционные имена на -ι передаются на «-и» (Хуси, Еффи, Архи); «-ий» — только для имён с устоявшейся русской формой (Левий, Верзеллий).
- Культовые термины Пятикнижия (единообразно в Исходе, Левите, Числах, Второзаконии): κάρπωμα — **приношение**; ἀφαίρεμα — **отъятие**; ἐπίθεμα — возложение; σεμίδαλις — **тонкая мука**; νόμιμον — **постановление** (νόμιμον αἰώνιον — постановление вечное); δικαίωμα — установление; πλημμέλεια — [жертва за] проступок; θυσία σωτηρίου — жертва спасения; ὀσμὴ εὐωδίας — запах благоухания; ἐξιλάσκομαι — совершить умилостивление / умилостивить; ἱλαστήριον — очистилище; ὑακίνθινος — гиацинтовый; κόκκινος — червлёный; βύσσος — виссон; ἐπωμίς — наплечник; λογεῖον — наперсник; ποδήρης — подир; δῆμος — род; οἶκος πατριῶν — отцовский дом; ἀποσκευή — домашние; προσήλυτος — пришелец; ἐν μηνὶ τῶν νέων — в месяце новых [плодов].
- «Милостив [будь] ко мне» для ἵλεώς μοι (не синодальное «далеко от меня»).

## Формат результата
Для каждой главы — JSON-файл:
```json
{"slug": "navin", "ch": "1", "verses": [{"v": "1", "r": "И было после смерти Моисея…"}, …]}
```
- Ровно те же номера стихов `v` и в том же порядке, что во входном файле.
- `r` — только русский текст перевода: без номера стиха, без греческих слов, без комментариев.
- Запись через Python (`json.dump(..., ensure_ascii=False)`) или инструментом Write. После записи обязательно запусти проверку `python3 check.py <путь к файлу>` и исправь всё, на что она жалуется.
